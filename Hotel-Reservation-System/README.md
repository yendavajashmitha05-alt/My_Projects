
# Hotel Reservation System

## Description
A console-based Hotel Reservation System developed using Java, JDBC, and MySQL.

## Technologies Used
- Java
- JDBC
- MySQL
- IntelliJ IDEA

## Features
- Reserve a room
- View all reservations
- Search reservation details
- Update reservation details
- Delete reservations

## Database
MySQL database: `hotel_db`

Table: `reservations`

## Concepts Used
- Java OOP concepts
- JDBC connectivity
- SQL CRUD operations
- PreparedStatement
